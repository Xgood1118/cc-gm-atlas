在现有 atlas 骨架上，把它做成一个能真正产出图集的打包器。保留 Rect、load_manifest、
pack、export_json、export_png 的现有名字与签名，只用 Python 标准库，不得引入第三方依赖，
不得改动 data/manifest.txt。

## 需要完成

1. **排布质量**
   - 给 512x512 的图集，当前清单的利用率要达到 85% 以上，并把这个数写进 README。
   - 条目之间要留边距，边距大小可配置，默认 1 像素。
   - 高瘦条目允许旋转 90 度以提升利用率，旋转过的条目要在 JSON 里标出来。

2. **重复条目**
   - 尺寸完全相同的条目共用同一块区域，JSON 里要能看出谁复用了谁。
   - 复用不能改变调用方按名字取帧的行为。

3. **图集图片**
   - 产出 PNG，尺寸与 `--width/--height` 一致。
   - 每个条目在图上有可区分的填充色，边界与 JSON 坐标逐像素对齐。
   - 同一份清单连续跑两次，两张 PNG 逐字节相同。

4. **边界情况**
   - 放不下时返回非零退出码并在标准错误里说明是哪个条目放不下。
   - 单个条目比图集还大时不能抛出未捕获异常。

5. **测试**
   - 覆盖：不重叠、旋转后不越界、重复条目复用、利用率下限、两次输出一致。
   - `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m atlas.cli data/manifest.txt --width 512 --height 512 --padding 1`，
把利用率、复用条目数、旋转条目数贴进 README。
